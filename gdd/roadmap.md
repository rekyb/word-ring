# Roadmap

## V1 — MVP (ship to Play)

1. Project scaffold (Expo + TS + expo-router + Zustand)
2. Dictionary + level generator + scoring (with tests)
3. Game screen (wheel, submit, feedback, hints, progress, stars)
4. Progress persistence + level map
5. AdMob (rewarded + interstitial) + remove-ads IAP
6. Firebase Analytics events
7. Polish (animations, SFX, haptics) + accessibility
8. Play Store assets (icon, screenshots, listing) + EAS build

**Launch content:** ~100 levels (generation makes scaling effectively free).
