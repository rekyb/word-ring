# UI/UX

## Screens

- **Level map** — grid of levels, stars shown per completed level.
- **Game screen** — the wheel, controls, progress, and found-words list.
- **Settings** — sound/haptics toggles, restore purchase, remove-ads.
- **Overlays** — celebration on clear, interstitial, hint/ad prompts.

## Game screen layout

- **9 letters** arranged on a ring.
- **Word-in-progress** displayed in the center.
- **Submit / clear** controls.
- **Progress bar + star meter** showing % found and star thresholds.
- **Found-words list** (or grid).
- **Shuffle / Reveal** buttons.

## Polish

- Pop animation on valid word.
- Shake on invalid word.
- Confetti on level clear.
- Subtle SFX and haptics on taps and correct words.

## Accessibility

- Large tap targets.
- **Colorblind-safe** states (state is never conveyed by color alone).
- Readable fonts and good contrast.
- Screen-reader labels on interactive elements.
